How setup works
  1. Add the example and enable its rule in Wireflip. Website rules start disabled and only apply to this origin.
  2. Return to this Playground tab → Wireflip toolbar icon → Start tab session. A session on the workspace tab does not apply here.
  3. Test the request. A received response alone does not prove a rule ran; use Inspector to verify other actions.

Requests contact the URL above. Firefox replaces the upstream body and preserves its HTTP status, so the endpoint must be reachable.
