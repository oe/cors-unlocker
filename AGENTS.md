# Store marketing assets

For store screenshots and promotional images, use the project-local Goldie skill
at `.agents/skills/goldie/SKILL.md` and the Chrome-specific workflow in
`marketing/chrome-web-store/README.md`.

This project ships browser extensions. Its current marketing target is Chrome
Web Store: 1280×800 screenshots, a 440×280 small promo tile, and an optional
1400×560 marquee. Adapt Goldie's design principles to these sizes; its mobile
simulators, device frames, CLI dimensions, and Apple/Play verification do not
apply here.

Keep the approved straight-on layout: readable benefit-led copy, actual extension
UI, no rotation, perspective, overlapping windows, or enlarged logo artwork.
Use `marketing/chrome-web-store/source/design.json` for copy and colors. Preserve
sample-data labeling and bundled font attribution when changing the assets.
