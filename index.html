Let your app ask for the capability it needs.

The open-source SDK connects a web app to the locally installed extension. Every request is bound to the real top-level page origin, and CORS changes require user consent.

  1. 1Connect locallyNo account, API key, or cloud relay.
  2. 2Ask for one capabilityCORS access is scoped to the current origin.
  3. 3Create safe draftsApps can prepare disabled rules; users review before enabling.

Local by design.

Traffic stays on your machine, and powerful access ends with the tab.

No traffic uploadRequests, responses, rules, and logs are not sent to our servers.
No native clientEverything runs inside Chrome or Firefox.
Sensitive headers redactedAuthorization and cookie values are masked in the inspector.
Tab sessionsSessions stop on disable, tab close, or cross-origin navigation. Persistent rules stay on until you turn them off.
