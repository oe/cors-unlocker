Wireflip 2.1.0

Enabled saved rules now run automatically on matching supported pages, including new matching tabs. Recording is separate: stopping recording does not stop saved rules. Disable the rule or its group to stop its changes. Previously enabled 2.0 Mock, delay and CORS rules may start running after the update without a tab session.

Website rule changes now require approval in a Wireflip-owned window. Explicitly trust an exact website origin in the popup to allow it to manage its own rules without repeated prompts. Access to login credentials still requires confirmation. Revoking trust restores prompts. Manually created, other-origin and older unowned rules stay under extension control.

The optional wireflip@2.1.0 SDK adds enableRule, disableRule and deleteRule. Older wireflip clients receive immediate upgrade guidance when approval is required, avoiding changes after an SDK timeout. Read-only access and the original cors-unlocker hosted bridge remain supported.

The workspace and Inspector have clearer editing, request verification and recovery controls, with all six supported languages. Temporary tab controls remain independent of saved rules.

Firefox response body replacement still contacts the upstream server and preserves its HTTP status. No Chrome debugger or HTTP cache bypass is claimed for Firefox.
